# shatlet النعنع 🌿

موقع تعريفي + مساحة عمل (Studio) لإدارة الملفات والمهام، بطابع «النعنع» من طرطوس — سوريا.
مبني بـ **Next.js 16** (App Router) + **TypeScript** + **Tailwind CSS 4** + **PostgreSQL** عبر **Drizzle ORM**.

## المزايا

- **موقع تعريفي**: هيرو، نبذة، خدمات، الطريقة، معرض صور، طقوس الحياة اليومية، ودفتر زوار حقيقي.
- **مساحة العمل `/studio`**: إضافة/تعديل/حذف الملفات، إدارة المهام، بحث وتصفية، ولوحة إحصاءات تُحدَّث لحظيًا.
- **API داخلي**: مسارات REST للملفات والمهام والرسائل والإحصاءات + فحص صحة `/api/health`.
- **قاعدة بيانات حقيقية**: الجداول `files` / `tasks` / `messages` مع بيانات بذور جاهزة في `seed.sql`.

## التشغيل محليًا

```bash
# 1) تثبيت الحزم
npm install

# 2) إعداد متغيرات البيئة (انسخ المثال ثم عدّل الرابط)
cp .env.example .env.local

# 3) إنشاء الجداول في PostgreSQL
npx drizzle-kit push

# 4) تعبئة بيانات تجريبية (اختياري)
psql "$DATABASE_URL" -f seed.sql

# 5) تشغيل خادم التطوير
npm run dev
```

ثم افتح <http://localhost:3000> للموقع و<http://localhost:3000/studio> لمساحة العمل.

## المتغيرات البيئية

| المتغير | الوصف | مثال |
| --- | --- | --- |
| `DATABASE_URL` | رابط اتصال PostgreSQL (مطلوب) | `postgresql://postgres:postgres@127.0.0.1:5432/app_db` |

## هيكل المشروع

```
src/
  app/                 صفحات App Router + مسارات API
  components/          مكوّنات الواجهة (أقسام الموقع + مساحة العمل)
  db/                  اتصال Drizzle + مخطط الجداول
  lib/                 بيانات الموقع، الاستعلامات، الأنواع، عميل الـ API
seed.sql               بيانات تجريبية للملفات والمهام والرسائل
drizzle.config.json    إعدادات Drizzle Kit
```

## ملاحظات

- `src/db/index.ts` يرمي خطأً إذا لم يكن `DATABASE_URL` معرّفًا، لذا لا تنسَ ملف البيئة قبل التشغيل.
- الصفحة الرئيسية وصفحة المكتب تستخدمان `force-dynamic` لأنها تقرأ من قاعدة البيانات مباشرة.
